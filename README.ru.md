<h1 align="center">Codex Limit Bar</h1>

Приложение строки меню macOS для просмотра лимитов Codex, времени обновления и доступных сбросов.

Это публичная витрина проекта. Исходники, актуальные сборки и инструкции находятся в [оригинальном репозитории](https://github.com/svllvsxprod/codex_limitbar). Полная копия исходного README сохранена [здесь](README.md).

**Темы:** `macos`, `menu-bar`, `usage-monitor`, `swiftui`
